<h1 align="center"> Introduction to Command Line & File System Management </h1>


---


## 1. Overview

The Linux command line is a text-based interface that allows users to interact with the operating system by entering commands in a terminal.

File system management involves navigating directories, creating and managing files, organizing data, and understanding how Linux stores information.

These skills are essential for Linux system administration, server management, networking, and cybersecurity.

## 2. Learning Objectives

By the end of this chapter, you should be able to:

- Understand the Linux terminal and shell.
- Execute basic Linux commands.
- Navigate the Linux file system.
- Create, copy, move, rename, and delete files and directories.
- Understand absolute and relative paths.
- Identify important Linux directories.
- Use command-line tools to manage files efficiently.

## 3. Understanding the Command Line

### 3.1 Terminal

A terminal provides an interface for entering commands and viewing their output.

### 3.2 Shell

A shell interprets commands and executes programs. Common Linux shells include:

| Shell | Description |
|---|---|
| `bash` | Bourne Again Shell; widely used in Linux. |
| `sh` | Traditional Unix shell interface. |
| `zsh` | An interactive shell with extensive customization. |
| `fish` | A user-friendly interactive shell. |

### 3.3 Basic Command Syntax

```bash
command [options] [arguments]
```

Example:

```bash
ls -l /home
```

| Component | Meaning |
|---|---|
| `ls` | Command that lists directory contents. |
| `-l` | Option that displays detailed information. |
| `/home` | Argument specifying the directory to list. |

## 4. Basic Linux Commands

| Command | Purpose | Example |
|---|---|---|
| `pwd` | Displays the current directory. | `pwd` |
| `ls` | Lists files and directories. | `ls -la` |
| `cd` | Changes the current directory. | `cd /etc` |
| `mkdir` | Creates a directory. | `mkdir lab` |
| `touch` | Creates an empty file if it does not exist. | `touch notes.txt` |
| `cp` | Copies files or directories. | `cp a.txt b.txt` |
| `mv` | Moves or renames files. | `mv old.txt new.txt` |
| `rm` | Removes files. | `rm notes.txt` |
| `cat` | Displays file contents. | `cat notes.txt` |
| `clear` | Clears the terminal display. | `clear` |
| `whoami` | Displays the current username. | `whoami` |
| `man` | Opens a command's manual page. | `man ls` |

## 5. Understanding the Linux File System

Linux uses a hierarchical file system that begins at the root directory, represented by `/`.

```text
/
├── bin/       Essential user commands
├── boot/      Boot-related files
├── dev/       Device files
├── etc/       System configuration files
├── home/      Users' home directories
├── lib/       Essential shared libraries
├── media/     Removable media mount points
├── mnt/       Temporary mount points
├── opt/       Optional application software
├── proc/      Process and kernel information
├── root/      Root user's home directory
├── run/       Runtime data
├── sbin/      System administration commands
├── tmp/       Temporary files
├── usr/       Applications and shared resources
└── var/       Variable data, including logs
```

Note: Exact directory contents vary by Linux distribution. Some directories, such as `/bin` and `/sbin`, may be symbolic links to directories under `/usr`.

## 6. Absolute and Relative Paths

### Absolute Path

An absolute path starts from the root directory `/`.

Example:

```bash
cd /home/user/Documents
```

### Relative Path

A relative path starts from the current working directory.

Example:

```bash
cd Documents
```

| Symbol | Meaning |
|---|---|
| `/` | Root directory |
| `.` | Current directory |
| `..` | Parent directory |
| `~` | Current user's home directory |

## 7. File and Directory Management

### Create a Directory

```bash
mkdir linux-lab
```

### Create Nested Directories

```bash
mkdir -p linux-lab/files/notes
```

### Create a File

```bash
touch notes.txt
```

### Copy a File

```bash
cp notes.txt backup.txt
```

### Rename a File

```bash
mv notes.txt linux-notes.txt
```

### Remove a File

```bash
rm linux-notes.txt
```

### Remove an Empty Directory

```bash
rmdir linux-lab
```

Be careful with `rm`: deleting files this way generally bypasses the desktop trash and may be difficult to reverse.

## 8. Getting Help

Linux provides built-in documentation and command help.

| Command | Purpose |
|---|---|
| `man ls` | Opens the manual for `ls`. |
| `ls --help` | Displays supported options for `ls`. |
| `help cd` | Shows help for a Bash built-in command. |
| `whatis ls` | Displays a short manual description, if available. |
