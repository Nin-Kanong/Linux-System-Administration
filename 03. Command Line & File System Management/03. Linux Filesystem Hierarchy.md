<h1 align="center"> Linux Filesystem Hierarchy </h1>


---

## Introduction 

The Linux Filesystem Hierarchy explains how Linux organizes files, folders, programs, configuration files, user data, and system information.

Linux uses a single directory tree that starts at the **root directory** (``/``).

---

## Linux filesystem structure

| Directory | Full name / meaning         | Purpose and explanation                                                                                                                                                             | Examples / common contents                                              |
| --------- | --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `/`       | Root directory              | The starting point of the entire Linux filesystem. All files, directories, devices, and mounted filesystems are organized under it.                                                 | `/home`, `/etc`, `/usr`, `/var`                                         |
| `/bin`    | Essential user binaries     | Contains essential commands used by users and system scripts. These commands are needed for basic system operation.                                                                 | `ls`, `cp`, `mv`, `cat`, `mkdir`, `rm`                                  |
| `/boot`   | Boot directory              | Contains files needed to start Linux, including the Linux kernel and bootloader-related files.                                                                                      | `vmlinuz`, `initramfs`, `grub/`                                         |
| `/dev`    | Device files                | Contains special files representing hardware devices and virtual devices. Linux uses these files to communicate with devices.                                                       | `/dev/sda`, `/dev/null`, `/dev/tty`, `/dev/zero`                        |
| `/etc`    | Configuration directory     | Stores system-wide configuration files. Administrators use these files to configure services, networking, users, and other system settings.                                         | `/etc/passwd`, `/etc/hostname`, `/etc/hosts`, `/etc/fstab`, `/etc/ssh/` |
| `/home`   | User home directories       | Stores personal directories and files belonging to regular users. Each user usually has their own directory.                                                                        | `/home/student/`, `/home/hello/`, `/home/user/`                         |
| `/lib`    | Essential shared libraries  | Traditionally stores essential shared libraries and kernel modules required by programs and the system.                                                                             | Shared libraries such as `libc.so`, kernel modules                      |
| `/media`  | Removable media mount point | Commonly used for automatically mounting removable storage devices.                                                                                                                 | USB drives, CDs, DVDs                                                   |
| `/mnt`    | Temporary mount point       | Commonly used by administrators to temporarily mount filesystems or storage devices.                                                                                                | `/mnt/usb/`, `/mnt/backup/`, `/mnt/data/`                               |
| `/opt`    | Optional software           | Used for additional application software packages that are not part of the basic operating system installation.                                                                     | `/opt/google/`, `/opt/application/`                                     |
| `/sbin`   | System binaries             | Traditionally contains system administration commands used for system maintenance and configuration.                                                                                | `fsck`, `reboot`, `shutdown`                                            |
| `/srv`    | Service data                | Stores data provided by services running on the system, such as web servers and file servers.                                                                                       | Website data, FTP files                                                 |
| `/tmp`    | Temporary files             | Stores temporary data created by applications and users. Files may be deleted automatically during reboot or by system cleanup policies.                                            | Temporary application files, temporary scripts                          |
| `/usr`    | User system resources       | Contains many applications, commands, libraries, documentation, and other resources shared by users and the system.                                                                 | `/usr/bin/`, `/usr/lib/`, `/usr/share/`                                 |
| `/var`    | Variable files              | Stores data that changes frequently while the system is running.                                                                                                                    | Logs, caches, mail, databases, application data                         |
| `/root`   | Root user's home directory  | The personal home directory of the administrator account named `root`. It is separate from `/home`.                                                                                 | `/root/.bashrc`, `/root/Downloads/`                                     |
| `/proc`   | Process filesystem          | A virtual filesystem that provides information about running processes and the Linux kernel. Most entries are generated by the kernel rather than stored as ordinary files on disk. | `/proc/cpuinfo`, `/proc/meminfo`, `/proc/1/`                            |

## 2. Subdirectories

These are examples of directories located inside other directories.

| Full path           | Parent directory | Explanation                                                              |
| ------------------- | ---------------- | ------------------------------------------------------------------------ |
| `/home/student`     | `/home`          | The personal home directory of a user named `student`.                   |
| `/home/student/dir` | `/home/student`  | A subdirectory created inside the student's home directory.              |
| `/home/linuxgym`    | `/home`          | Another example of a user's personal home directory.                     |
| `/usr/local`        | `/usr`           | Stores software and files installed locally by the system administrator. |
| `/usr/local/bin`    | `/usr/local`     | Stores executable commands and programs installed locally.               |
| `/usr/local/games`  | `/usr/local`     | A traditional location for locally installed games, when used.           |

Example of the hierarchy:

```
/
├── home/
│   ├── student/
│   │   └── dir/
│   └── linuxgym/
│
└── usr/
    └── local/
        ├── bin/
        └── games/
```

Remember: `student`, `dir`, and `linuxgym` are example names, not mandatory Linux directories.

## Important subdirectories

| Directory      | Full meaning / purpose                                                                         | Examples                             |
| -------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------ |
| `/usr/bin`     | Main location for most user commands and executable programs.                                  | `python3`, `gcc`, `git`              |
| `/usr/sbin`    | Contains system administration programs that are not essential for basic booting and recovery. | Administration utilities             |
| `/usr/lib`     | Contains libraries and supporting program files.                                               | Application libraries                |
| `/usr/share`   | Stores shared, architecture-independent data.                                                  | `/usr/share/doc/`, `/usr/share/man/` |
| `/usr/include` | Contains header files used in software development.                                            | `stdio.h`, `stdlib.h`                |
| `/usr/src`     | Stores source code, including optional kernel source packages.                                 | Linux kernel source                  |
| `/var/log`     | Stores system and application log files.                                                       | `syslog`, `auth.log`, `kern.log`     |
| `/var/cache`   | Stores application cache data that can generally be regenerated.                               | Package manager cache                |
| `/var/lib`     | Stores changing application and service state data.                                            | Package and service databases        |
| `/var/spool`   | Stores queued work waiting to be processed.                                                    | Mail and print queues                |
| `/var/tmp`     | Stores temporary files that are intended to survive reboots longer than files in `/tmp`.       | Temporary application data           |
| `/var/mail`    | Stores user mailbox data, when this system uses this location.                                 | User mailboxes                       |
| `/var/opt`     | Stores variable data belonging to add-on packages installed in `/opt`.                         | Application state data               |

These directory purposes follow the Filesystem Hierarchy Standard (FHS).



## 4. Additional important Linux directories

Your image does not show every directory commonly found on modern Linux systems.

| Directory     | Name                      | Purpose                                                                                                  | Examples                       |
| ------------- | ------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------ |
| `/run`        | Runtime data              | Holds temporary information about currently running processes and services.                              | PID files, sockets             |
| `/sys`        | System filesystem         | Provides information about hardware devices, drivers, and kernel interfaces.                             | `/sys/class/`, `/sys/devices/` |
| `/lost+found` | Recovered files directory | May be created on certain Linux filesystems to store recovered file fragments after filesystem checking. | Recovered files                |

`/run` is part of the FHS, while `/proc` and `/sys` provide Linux kernel information through virtual filesystems.
